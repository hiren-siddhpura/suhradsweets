# Payment receipts

Purchase documents currently use manually entered Google Drive view links. There is no Purchase upload or private file proxy to reuse. Customer payment proofs use private Firebase Storage objects instead. Only metadata and the object path are stored in Firestore. The Storage rules allow authenticated users to create an object for an invoice they own; staff may submit for another invoice. Client reads and changes to objects are denied. An authenticated callable checks the payment's owner or active staff role before returning receipt bytes. Receipt URLs are never stored or shared.

Firebase requires the Blaze pay-as-you-go plan to use Cloud Storage, including existing default buckets. See [Firebase's billing FAQ](https://firebase.google.com/docs/storage/faqs-storage-changes-announced-sept-2024). Before deployment, confirm that the `suhrad-sweets-oms.firebasestorage.app` bucket exists and billing is enabled. Deploy `storage.rules`, Functions and Hosting together. If the bucket name differs, set `PAYMENT_RECEIPTS_BUCKET` in the Functions environment. No billing setting or deployment is changed by this repository edit.

Proof is optional for cash and required for UPI or bank transfer. The browser checks extension, MIME type and size. Storage rules limit size, type, invoice ownership and create-only access. Submission checks the stored object's signature, size, MIME type and invoice metadata. A receipt can be previewed before submission and, after submission, opened or downloaded by the payment owner or staff through `readPaymentReceiptCall`. Payment records retain submitter, submission time, receipt reference, reviewer, review time, status and rejection reason. Existing invoice reconciliation remains in the payment operations.

An upload that succeeds while payment submission fails is retained at its private path so the same form can retry. Replacing an already uploaded file creates a new operation ID and can leave an unreferenced object. Set up periodic cleanup of unreferenced objects before production use.
